# 남양주시장애인복지관 전자 기탁서 PWA

GitHub Pages에 그대로 올려 사용할 수 있는 정적 웹앱(PWA)입니다.

## 포함 양식
- 비지정후원금 기탁서
- 지정후원금 기탁서
- 현물 기탁신청서
- CMS 후원: **비지정후원금 기탁서 + CMS 이용 신규신청서**를 한 번에 작성하고 하나의 PDF로 생성

## GitHub Pages 설정
1. 이 폴더 안의 파일을 GitHub 저장소 최상위(root)에 모두 업로드합니다.
2. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`의 Source를 **Deploy from a branch**로 설정합니다.
4. Branch를 `main`, Folder를 `/(root)`로 선택하고 Save 합니다.
5. 표시되는 `https://계정명.github.io/저장소명/` 주소를 태블릿 Chrome/Edge에서 엽니다.
6. 브라우저 메뉴에서 **앱 설치 / 홈 화면에 추가**를 선택합니다.

## 데이터 저장 방식
- 입력한 개인정보/서명은 서버나 GitHub로 전송하지 않습니다.
- 완료한 PDF는 브라우저의 IndexedDB(앱 내부 저장공간)에 보관됩니다.
- 작성 완료 시 PDF 다운로드도 자동 시작합니다.
- 홈 화면의 저장 목록에서 PDF를 다시 다운로드하거나 기기 내부 기록을 삭제할 수 있습니다.
- 내부 서버 보관이 필요하면 태블릿 `다운로드` 폴더의 PDF를 USB/내부망 파일전송 방식으로 옮기는 것을 권장합니다.

## 중요
- 웹앱은 운영체제 보안정책 때문에 사용자가 지정한 임의의 폴더에 무조건 자동 저장할 수는 없습니다. 기본적으로 브라우저의 다운로드 폴더로 저장됩니다.
- 주민등록번호, 계좌정보, 서명이 포함될 수 있으므로 공용 클라우드 저장소에 PDF를 자동 업로드하지 않도록 설계했습니다.
- 태블릿 분실에 대비해 화면 잠금/기기 암호화/업무용 계정 분리를 권장합니다.
- 현재 CMS 화면은 업로드된 파일 제목과 내용인 **「CMS 이용 신규신청서」**를 기준으로 전자화했습니다. 일반 후원자의 CMS 출금동의서가 별도 양식이라면 해당 파일로 교체하는 것이 맞습니다.

## 파일 구성
- `index.html` 화면
- `styles.css` 디자인
- `app.js` 입력/전자서명/PDF 생성/로컬저장
- `manifest.webmanifest` PWA 설치정보
- `sw.js` 오프라인 캐시
- `icons/` 앱 아이콘
