# 남양주시장애인복지관 S펜 전자 기탁서

이 버전은 입력폼이 아니라 **원본 기탁서 PDF 위에 S펜으로 직접 필기**하는 방식입니다.

## 반드시 먼저 할 일
브라우저는 HWP를 원본 모양 그대로 표시할 수 없습니다. 현재 사용 중인 HWP 4종을 한글에서 `PDF로 저장`한 뒤 아래 파일명으로 `templates` 폴더에 넣어주세요.

- 비지정후원금 기탁서 -> `templates/general.pdf`
- 지정후원금 기탁서 -> `templates/designated.pdf`
- 현물 기탁신청서 -> `templates/goods.pdf`
- CMS 신청서 -> `templates/cms.pdf`

PDF의 페이지 수는 몇 장이어도 됩니다.

## CMS 후원
CMS 후원을 선택하면 앱이 자동으로
1. `general.pdf` 비지정후원금 기탁서
2. `cms.pdf` CMS 신청서
순서로 이어서 보여줍니다. 완료하면 두 문서와 모든 필기가 합쳐진 PDF 1개가 저장됩니다.

## GitHub Pages 배포
저장소 최상위에 이 폴더의 파일을 그대로 올린 후:
Settings -> Pages -> Deploy from a branch -> main -> /(root)

## 사용
삼성 태블릿에서 Chrome으로 GitHub Pages 주소 접속 -> 앱 설치/홈 화면에 추가.
원본 서류 위에 S펜으로 직접 작성 -> `완료 · PDF 저장`.

## 개인정보
작성한 필기와 완성 PDF는 GitHub에 업로드하지 않습니다. PDF 생성은 브라우저 안에서 처리되고 다운로드된 파일은 태블릿에 저장됩니다.

## 참고
첫 실행에서는 PDF 렌더링/저장 라이브러리를 CDN에서 불러오기 때문에 인터넷 연결이 필요합니다. 이후 서비스워커 캐시에 남으면 오프라인 사용이 가능하지만, 기관용으로 완전 오프라인을 보장하려면 라이브러리 파일을 저장소에 직접 포함하는 방식으로 바꾸는 것을 권장합니다.
